# git-gud-wif-ai

Claude Code project template repository. The distributable template lives in `Claude-Code-Template-V6.5.2/`.

## Project Structure

```
git-gud-wif-ai/
├── Claude-Code-Template-V6.5.2/   # The template — copy into new projects
└── README.md                       # Public-facing documentation
```

## What This Repo Is For

- Distributing the Claude Code Template (V6.5.2)
- NOT a code project — no builds, no tests, no deployment

## Conventions

- Templates are self-contained — each template folder should work when copied to a new project
- See `Claude-Code-Template-V6.5.2/README.md` for template usage docs
